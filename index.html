Core architecture

Policy, execution, and context are separated by design.

ASON evaluates submitted plans against policy. APEX validates and executes accepted sequences. RAG provides retrieval and storage through explicit interfaces.

01 / Policy

ASON

Evaluates submitted plans against caller-supplied policy before any sequence is submitted for execution.

02 / Runtime

APEX

Validates, records, and executes accepted tool sequences within configured runtime limits.

03 / Context

RAG

Provides retrieval and storage through library and versioned HTTP interfaces.
